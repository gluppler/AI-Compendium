This module covers the theoretical foundations of AI, including supervised, unsupervised, and reinforcement learning, core algorithms, and deep learning architectures.

# Module summary

Understanding the technology underlying AI, ML, and DL systems is a prerequisite for reasoning about their behavior and security implications. This module serves as both an entry point for newcomers and a reference for the key concepts that underpin the field.

Mathematics appears throughout where it adds precision, but it is not the primary focus. The goal is conceptual fluency — enough to approach more advanced, practical topics with confidence.

Topics covered:

- Supervised learning: labeled-data training with linear regression, logistic regression, decision trees, and support vector machines.
- Unsupervised learning: k-means clustering and principal component analysis for unlabeled data.
- Reinforcement learning: agent-environment interaction and reward maximization via Q-learning and SARSA.
- Deep learning: perceptrons, MLPs, CNNs, and RNNs.
- Generative AI: large language models and the mechanisms behind them.

This module is entirely conceptual — no hands-on exercises or assessments are included.

The module is classified as "Medium" and assumes working knowledge of:

- Python programming fundamentals
- Basic statistics (recommended)
- Linear algebra (recommended)
- Calculus (recommended)

There is no time limit. Complete all sections to mark the module as finished in any associated learning path.
