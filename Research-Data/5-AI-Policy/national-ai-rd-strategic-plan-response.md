# Dreadnode Response to the 2025 National AI R&D Strategic Plan

**Source:** dreadnode.io/research/national-ai-research-and-development-strategic-plan-response
**Author:** Daria Bahrami
**Date:** June 3, 2025

## Key Recommendations

1. **Strengthen AI security through data science and adversarial testing** — R&D funding should prioritize the development of systematic, reproducible evaluation methodologies for AI systems. The current ad-hoc approach to AI security assessment does not scale.

2. **Invest in dual-use evaluation infrastructure** — Platforms that serve both offensive (red teaming, vulnerability discovery) and defensive (hardening, continuous monitoring) purposes create a virtuous cycle of security improvement.

3. **Fund open-source security tooling** — The security research community needs shared infrastructure for building, testing, and deploying AI security agents. Open-source contributions (Rigging, Strikes SDK, AIRTBench) demonstrate the model.

4. **Bridge academic research and operational deployment** — The gap between research papers and production-ready security tools requires funding for applied research that translates academic findings into operational capabilities.

## Relevance to This Workspace

Supports the workspace approach of systematic, evidence-based AI security evaluation using reproducible methodologies.
