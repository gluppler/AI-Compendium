This module introduces red teaming of AI systems and ML-based deployments. It surveys common security vulnerabilities in these systems and the attack vectors that target their components.

## Module summary

Assessing ML-based systems demands a solid understanding of their security vulnerabilities, how ML components interact with traditional infrastructure, and how those interactions create exploitable conditions. This module provides a broad foundation for security assessments of ML-based systems and generative AI.

Topics covered:

- ML OWASP Top 10
- LLM OWASP Top 10
- Attacking ML-based systems and their components

Each section includes hands-on exercises. The module ends with a practical skills assessment. There is no time limit; completing all exercises and the assessment earns full credit and marks the module complete in any active paths.

Prerequisites:

- [Fundamentals of AI](https://academy.hackthebox.com/module/details/290)
- [Applications of AI in InfoSec](https://academy.hackthebox.com/module/details/292)
